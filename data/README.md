Đặt dữ liệu đầu vào trong thư mục này với tên:

`hotel_bookings_synthetic_200MB.csv`

Chạy `./scripts/run.sh` từ thư mục gốc project để nạp lần đầu lên HDFS. Nếu file đã có trên HDFS, script dùng lại file đó; không cần bản local để khởi động lại.

CSV trong thư mục này được Git bỏ qua và không được đưa lên repository. Mỗi thành viên chuẩn bị bản dữ liệu riêng.
